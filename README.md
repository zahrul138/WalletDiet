
# WalletDiet 💸

**Because Money Doesn't Save Itself.**

WalletDiet is a personal finance management application designed to help users track their income, expenses, and manage their money more effectively.

## ✨ Features

- **Dashboard** – View your financial overview and current balance.
- **Income Tracking** – Record and monitor your income.
- **Expense Tracking** – Manage and categorize your daily expenses.
- **Transaction History** – Review your previous financial transactions.
- **User Authentication** – Register, log in, and manage your account.
- **Password Reset** – Reset your password through email verification.

## 🛠️ Built With

- C#
- ASP.NET Core MVC
- HTML
- CSS
- JavaScript
- SQL Server
- Entity Framework Core

## 🚀 Getting Started

### Prerequisites

- Visual Studio 2022
- .NET SDK (compatible with the project)
- SQL Server

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/zahrul138/WalletDiet.git
   ```

2. Open `WalletDiet.sln` in Visual Studio 2022.

3. Configure your database connection string using User Secrets.

4. Configure your email settings using User Secrets.

5. Run the application.
